Reproducibilidad en 1 Comando & Higiene de Git

Ejecución de todo el pipeline en 22 segundos sin subir binarios pesados al repositorio

¿Por qué?

Ejecutar 5 scripts sueltos y luego comandos manuales de dbt propicia errores de orden, y subir data/silver/ o *.duckdb a GitHub contamina el repositorio con archivos binarios pesados.

¿Cómo?

Creamos el orquestador src/transformar.py (python -m src.transformar) que ejecuta toda la Capa Plata, el reporte de calidad y dbt build en un solo paso, y configuramos .gitignore.

¿Para qué?

Para permitir que cualquier evaluador o integrante reconstruya Plata + Oro + 82 pruebas de dbt con un único comando en ~22 segundos manteniendo limpio el repositorio.

En simple

Un solo comando (python -m src.transformar) reconstruye y verifica todo el proyecto sin subir bases de datos pesadas a Git.

1. Construir Plata + Reporte + Oro:
python -m src.transformar

Limpia las 5 fuentes, escribe docs/reporte_calidad.md y corre dbt build en ~22 segundos.

2. Ejecutar Pruebas y Consultas:
python -m pytest -v
python -m src.consultar --solo-oro
🛡️ Protección del Repositorio (.gitignore activo):

Están excluidos de Git: data/bronze/, data/silver/, data/observatorio.duckdb, dbt/target/, dbt/logs/ y dbt/.user.yml, manteniendo el repositorio liviano y el código 100 % reproducible desde scripts.
